# Task handoff template

Copy this structure into a new note with a unique id, type session, active status, dates, source, confidence and tags. Replace placeholders before use.

## Read set

List the notes read and why they constrain this task. Record status, confidence, stale assumptions and missing coverage.

## State before work

Record actual repository state and existing test evidence. Link the selected issue, requirements, decisions and previous session.

## Scope and acceptance

Name the task and measurable acceptance. Distinguish approved requirements from proposed targets.

## Plan before implementation

Record implementation steps, verification, dependencies, risks and recovery. Write this section before editing implementation files.

## Closeout

Record files/behavior changed, actual check commands/outcomes, remaining blockers, issue status and next action. Link the session summary. Publication is verified through Git history and the remote.
